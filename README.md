# Photocard Print

Site estático para montar PDFs A4 de photocards frente e verso diretamente no navegador.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos.
2. Em **Settings → Pages**, selecione **GitHub Actions** como fonte.
3. O fluxo incluído publicará automaticamente a pasta `dist`.

O site não envia fotos para nenhum servidor. A geração do PDF acontece localmente no navegador.
